# RASS — nezvanični demo

Next.js demonstracijski koncept za kopirnicu, izradu ključeva i pečata u Sarajevu. Ovo nije službena stranica radnje; indeksiranje je isključeno u metapodacima i `robots.txt`.

Poslovni podaci, javni izvori i Google Maps upiti nalaze se u `business.ts`. Radno vrijeme je preuzeto iz javnog imenika i treba ga potvrditi s vlasnikom. Embed je pretraga po nazivu i adresi, bez tvrdnje o tačnom ulazu; vidljivi Maps link ostaje rezervna opcija.

Za lokalni rad: `npm ci`, `npm run dev`, `npm run typecheck`, `npm run build`.

Space Grotesk i IBM Plex Sans se isporučuju lokalno kroz Fontsource variable pakete. Njihove OFL licence nalaze se u `licenses/`.
